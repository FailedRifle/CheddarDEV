# Orange Roulette

This tense decision-making puzzle game adapts high-stakes elimination mechanics into a stylized, randomized format. You weigh probabilities carefully with every turn to avoid triggering a loss condition.

---

### Performance & Specifications

* **FPS:** Stable UI rendering.
* **Load Time:** Instant round starts.
* **Latency:** Responsive menu navigation.
* **Multiplayer:** Unsupported.
