# People Playground

This physics sandbox game allows you to experiment with a wide array of weapons, sharp objects, explosives, and medical items on ragdoll humans. Every interaction is governed by a detailed physics engine, letting you test out creative and destructive scenarios in an open-ended environment.

---

### Performance & Specifications

* **FPS:** Smooth and consistent during standard object manipulation.
* **Load Time:** Rapid execution for immediate sandbox access.
* **Latency:** Precise, responsive mouse interaction for placement and destruction.
* **Multiplayer:** Unsupported.
