# BALDI'S BASICS

A surreal, surrealist horror game disguised as an educational 90s edutainment title. Players must collect all notebooks scattered across a confusing schoolhouse while evading Baldi and an eclectic cast of bizarre faculty members who react aggressively to incorrect answers and hallway infractions.

---

### Performance & Specifications

* **FPS:** Smooth and consistent framerate across modern hardware.
* **Load Time:** Instantaneous startup for quick, arcade-style runs.
* **Latency:** Low-latency input response essential for tight corridor navigation.
* **Multiplayer:** Unsupported.
