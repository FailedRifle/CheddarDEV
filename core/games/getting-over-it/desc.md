# Getting Over It

This punishing climbing game features a man trapped in a cauldron using a massive Yosemite hammer to scale a surreal mountain of bizarre objects. Every swing relies heavily on physics and momentum, where a single mistake drops you all the way back to the bottom.

---

### Performance & Specifications

* **FPS:** Steady engine performance for physics accuracy.
* **Load Time:** Quick initial spawn.
* **Latency:** Direct mouse-to-hammer tracking precision.
* **Multiplayer:** Unsupported.
